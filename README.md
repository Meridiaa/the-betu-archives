# The Betu Archives ♡

An intentionally unserious Y2K-style boyfriend appreciation website made by Pahad for Betu.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Share it

Pushing this repository to GitHub shares the source code. It does **not** automatically make the React website interactive from the repository page.

If you want Betu to open the live website in a browser, enable GitHub Pages or use another static host. No backend or database is needed for this project.
